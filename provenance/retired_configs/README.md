# Retired configuration presets

These rate-conversion presets are retained unchanged for historical inspection,
but are no longer installed. A read-only scan of all 90,526 saved Hydra configs
under the scoped paper result tree found no matching preset names in configs or
overrides, and no exact preprocessing-chain matches. No read/parse errors were
reported. The actual shared upsampler remains: 435 configs use upsampling.

This establishes absence in the inspected result tree, not every external user's
configuration. Restore a preset into an external Hydra preprocessor group if
needed; do not change the shared numerical implementation merely to prune files.
